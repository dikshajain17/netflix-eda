
# Netflix Dataset EDA 📊

This project performs **Exploratory Data Analysis (EDA)** on the Netflix Titles dataset to uncover insights about content trends, genre distribution, release patterns, ratings, and movie durations. The analysis includes **data cleaning, preprocessing, and visualization** to better understand Netflix’s content library.

## Project Summary
- **Total titles analysed:** 8,793  
- **Total columns:** 17  
- **Unique genres:** 42  
- **Year range:** 1925–2021  
- **Content added after 2015:** 99.4%  
- **Average movie duration:** 100 minutes  
- **Total visualisations created:** 15  

## Objectives
- Clean and preprocess raw Netflix dataset  
- Analyze trends in content release over the years  
- Study genre and rating distributions  
- Compare movies and TV shows  
- Generate insights through visualizations  

## Tools & Libraries Used
- **Python**
- **Pandas**
- **NumPy**
- **Matplotlib**
- **Seaborn**
- **Jupyter Notebook**

## Key Insights
- Majority of Netflix content was added **after 2015**
- Movies dominate the platform compared to TV shows
- Average movie duration is approximately **100 minutes**
- Significant growth in content release observed in recent years

## Visualizations Included
- Genre distribution charts  
- Content release trend analysis  
- Rating category analysis  
- Heatmaps  
- Time-series plots  
- Duration distribution charts
